# Tailfin feedback

This is where players of the Tailfin closed alpha send feedback and report bugs. There is no game code here.

**To send feedback:** in the game, open Help → Send feedback, answer the three questions and click Copy. Then [open a new feedback post](https://github.com/dukea043/tailfin-feedback/issues/new?template=feedback.yml) and paste it in.

**To report a bug:** [open a bug report](https://github.com/dukea043/tailfin-feedback/issues/new?template=bug.yml). A bug report save from the game helps a lot.

Posts here are public, so please leave out personal details you don't want shared. You need a free GitHub account to post.
